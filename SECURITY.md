# UnionKey Security Policy

Security is a core requirement for UnionKey. If you believe you have found a
vulnerability, please report it privately and do not open a public issue.

## Reporting a vulnerability

Send the report to `support@unionkey.io` with the subject
`[Security] Vulnerability report`.

Include the affected version, platform, reproduction steps, expected and actual
behavior, security impact, and any proof-of-concept material that helps us
validate the issue. Do not include wallet recovery phrases, private keys, or
other user secrets.

We will acknowledge the report, investigate it, and coordinate disclosure after
a fix is available. Please avoid accessing data that does not belong to you,
disrupting services, or taking actions that could harm users.

This responsible-disclosure policy is not a bug-bounty program. UnionKey does
not currently promise cash rewards, and no third-party bounty page is
authorized by this policy.

## Scope

This policy covers code maintained in the `UnionKeyHQ/app-monorepo` repository
and the official UnionKey desktop and mobile releases built from it. Third-party
dependencies are governed by their respective maintainers' security policies.
