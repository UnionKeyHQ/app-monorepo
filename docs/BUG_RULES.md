# UnionKey security reports

Do not disclose suspected security vulnerabilities in a public issue.

Report vulnerabilities using the private process documented in
[`SECURITY.md`](../SECURITY.md). The policy identifies the official UnionKey
contact, covered repository, expected report contents, and response process.

UnionKey does not promise a bounty or a specific payment through this document.
Any reward must be confirmed separately in writing by an authorized UnionKey
representative.

For ordinary product defects that do not expose confidential data, funds,
authentication, authorization, signing, update delivery, or build security, use
the [UnionKey issue tracker](https://github.com/UnionKeyHQ/app-monorepo/issues).
